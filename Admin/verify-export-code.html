🔐 Verifikasi Kode Export

Admin-only. Cocokkan kode verifikasi yang tertera di file "Export HTML" mahasiswa (Modul 1-14 maupun UTS/UAS) terhadap poin resmi di server saat kode itu dibuat.
⚠ File export HTML dibuat 100% di browser mahasiswa dan bisa diedit manual (skor, kode, dsb). Kode verifikasi TIDAK mencegah edit — tapi kalau field apa pun (poin/NIM/waktu dibuat) diubah, kode ini otomatis tidak cocok lagi. Salin ke-4 nilai di bawah persis seperti yang tertera di bagian "🔐 Kode Verifikasi" pada file export.
